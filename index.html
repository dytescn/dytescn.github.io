Install

一个二进制，装好就能用

选择平台复制安装命令。已经安装 dytes 时，用 dytes self-update 升级到最新版。

$ curl -fsSL https://www.dytes.cn/install.sh | sh> irm https://www.dytes.cn/install.ps1 | iex
安装到 ~/.local/bin macOS Linux Windows

Why dytes

为设计软件而生的极简包管理器

01

一个二进制

安装、更新、发布、自检都在一个 Rust 二进制里完成，不需要额外运行时。

02

声明式依赖

用 dytes.json 声明依赖，用 dytes.lock 固定版本，环境可重建。

03

图形安装与更新

dytes install --gui 与 dytes update --gui 提供图形窗口；命令行仍支持离线、仅检查与按类型更新。

04

一条命令发布

dytes publish 上传产物、清单与索引，保持发布可追溯。

05

多平台一致

Windows、Linux、macOS 使用同一套包模型与命令。

06

设计生态

连接设计插件、素材、工作区与对话能力，为设计工作流提供基础。

Quick start

从一份清单开始

写一份 dytes.json，初始化、校验、发布三步完成。

初始化一个设计插件包 shell 
$ dytes init --type design_plugins --name my_plugin
# 编辑 dytes.json，补全 mcp / exports 与平台导出
$ dytes check
$ dytes publish --dry-run
$ dytes publish

已经安装？

安装或升级到最新版，检查更新，或查看当前版本。

$ dytes self-update
$ dytes --version
$ dytes update --check
$ dytes update --gui

Product

从 dytes 到 Piksel

Piksel 是打开即用的设计协作产品，dytes 负责安装和更新它。 0.2.25 起，dytes install 默认安装 Piksel。

  1. 1
    安装 dytes

    把包管理器装到本机。

  2. 2
    安装 Piksel

    执行 dytes install core piksel --gui，在图形安装器中选择安装目录。

  3. 3
    启动

    从安装目录运行 piksel.exe、piksel.bin 或 piksel.app。

查看 Piksel
macOS / Linux
$ curl -fsSL https://www.dytes.cn/install.sh | sh

$ dytes install core piksel --gui
Windows PowerShell
> irm https://www.dytes.cn/install.ps1 | iex
> dytes install core piksel --gui
