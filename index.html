Install

一条命令，开始使用 dytes

选择平台，复制安装命令。也可以直接下载对应平台的二进制。

$ curl -fsSL https://www.dytes.cn/install.sh | sh> irm https://www.dytes.cn/install.ps1 | iex
安装到 ~/.local/bin macOS Linux Windows

Why dytes

为设计团队准备的包管理器

01

插件与能力包

统一管理设计插件、设计软件、Web 能力、系统库与模型包。

02

版本与依赖

用 dytes.json 声明依赖，用 dytes.lock 固定版本。

03

一条命令更新

dytes update 检查并安装更新，支持离线、检查和初始化脚本。

04

发布到对象存储

dytes publish 上传产物、清单与索引，保持发布可追溯。

05

多平台

Windows、Linux、macOS 使用同一套包模型与命令。

06

AI 设计生态

连接插件、素材、工作区与对话能力，为设计工作流提供基础。

Quick start

从清单开始

把包声明写进 dytes.json，剩下的交给 dytes。

初始化一个设计插件包 shell 
$ dytes init --type design_plugins --name my_plugin
$ dytes publish --dry-run
$ dytes publish

已经安装？

检查更新，或查看当前版本与配置。

$ dytes --version
$ dytes update --check
$ dytes update

Product

从 dytes 到 Piksel

dytes 是包管理器，Piksel 是客户实际打开的设计协作产品。 三步完成安装与首次更新。

  1. 1
    安装 dytes

    把包管理器装到本机。

  2. 2
    同步 Piksel 清单

    下载 Piksel 的 dytes.json 到工作目录。

  3. 3
    执行 dytes update

    dytes 会下载并安装 Piksel 及其依赖。

查看 Piksel
macOS / Linux
$ curl -fsSL https://www.dytes.cn/install.sh | sh

$ mkdir -p piksel && cd piksel
$ curl -fsSL https://raw.githubusercontent.com/dytescn/Piksel/main/dytes.json -o dytes.json

$ dytes update
Windows PowerShell
> irm https://www.dytes.cn/install.ps1 | iex
> mkdir piksel; cd piksel
> irm https://raw.githubusercontent.com/dytescn/Piksel/main/dytes.json -OutFile dytes.json
> dytes update
